# 💻 AgriIntel Frontend Client (React PWA)

Progressive Web App built with React.js, TailwindCSS, and Zustand.

## Key Features
- **Responsive PWA Shell**: Offline cache support for farmers with intermittent network access.
- **Role-Based Views**: Dashboards customized for Farmer, Buyer, Laborer, and Admin.
- **Interactive Crop & Disease Diagnosis**: Camera integration for real-time leaf image upload.
- **Real-Time Communication**: Socket.io integration for instant buyer-seller and farmer-labor negotiations.
- **Voice Assistant Interface**: Audio capture for Whisper STT and web audio playback for responses.

## Getting Started
```bash
npm install
npm start
```
Runs on `http://localhost:3000`.
